# ConsentSync QA Testing

## Project Overview
This project documents manual functional and UI testing of **ConsentSync – Control Your Data**, a Chrome extension designed to help users manage website privacy, monitor permissions, analyze policies, and access GDPR-related controls.

## Application Details
- **Application:** ConsentSync – Control Your Data
- **Version:** 0.6.1
- **Testing Type:** Manual Functional Testing and UI Testing
- **Environment:** Google Chrome 155, Windows 11

## Testing Scope
The following areas were reviewed:
- Extension installation and popup
- Dashboard and navigation
- Privacy overview
- Live Monitoring
- Policy Analyzer
- Smart Preferences
- Consent Log
- GDPR Controls
- Website workflow

## Test Results
- **Total test cases:** 17
- **Passed:** 17
- **Failed:** 0

Results are documented based on the manual testing performed.
